# 官网正式上线

经过数月的打磨，晚夜工作室官方网站正式上线了。这是一个开始，也是我们把想法落地的第一块基石。

## 这次我们做了什么

- 从零搭建了整个站点的内容架构与视觉体系
- 建立了完整的后台内容管理系统，支持 Markdown 写作
- 文章正文以本地文件方式存储，读取更快、迁移更轻
- 做好了阅读去重、防注入等基础安全能力

## 关于技术选型

站点采用 **PHP + MySQL** 的经典组合，没有任何重型框架，也没有外部网络依赖，所有组件都已本地化：

```php
// 文章正文读取：先查数据库拿到编号，再读本地正文
$post = db_one('SELECT * FROM isw_posts WHERE id = ? AND status = 1', array($id));
$content = get_post_content($id); // data/posts/{id}.html
```

这样做的好处是，数据库里只保留编号、标题、作者、IP、点击量等元信息，正文这种"重资产"交给文件系统，既轻量又便于备份。
